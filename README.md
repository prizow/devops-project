# DevOps Infrastructure Project

Цей проєкт демонструє базові навички побудови сучасної інфраструктури, контейнеризації, моніторингу та CI/CD. Проєкт розгорнуто в середовищі WSL (Ubuntu) з використанням Docker.

## 🛠 Технологічний стек
* **Основа:** Linux (WSL), Bash-скрипти
* **Контейнеризація:** Docker, Docker Compose
* **Веб/Проксі:** Nginx, Python App
* **База даних:** PostgreSQL (з налаштованим Persistent Volume)
* **Моніторинг:** Prometheus, Grafana, Node Exporter
* **Логування:** Loki, Promtail
* **CI/CD:** GitHub Actions + локальний Self-hosted Runner

## 🚀 Реалізований функціонал
1. **Автоматизація розгортання:** Налаштовано CI/CD пайплайн. Будь-який push у репозиторій автоматично розгортається на локальному сервері через GitHub Runner.
2. **Reverse Proxy:** Nginx приймає трафік і проксіює його на контейнер із додатком.
3. **Робота з даними:** Піднято PostgreSQL. Написані Bash-скрипти (`backup.sh` та `restore.sh`) для автоматизованого резервного копіювання та відновлення бази даних.
4. **Моніторинг та Логи:** 
   - Grafana відображає метрики навантаження системи (CPU, RAM, Disk) через Prometheus та Node Exporter.
   - Усі логи Docker-контейнерів автоматично збираються через Promtail та доступні для пошуку в Grafana (через Loki).
5. **Безпека:** Налаштовано доступ до сервера за допомогою SSH-ключів.

## ⚙️ Запуск проєкту
Для розгортання проєкту достатньо мати встановлений Docker та запустити команду:
`docker compose up -d`
